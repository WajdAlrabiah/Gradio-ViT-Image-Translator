# Gradio ViT Image & Translation Web App

This repository contains a **Gradio web application** that demonstrates two AI capabilities:
1. **Image Classification** using a fine-tuned **Vision Transformer (ViT)** model.
2. **Text Translation** between English and French using **Facebook's NLLB-200 model**.

---

## Features
- **Image Classification:** Upload an image and get its predicted class (e.g., dog, cat, airplane, etc.).
- **Text Translation:** Translate English text into French instantly.
- **Interactive UI:** Powered by **Gradio**, allowing easy use via the browser.
- **Transformer Models:** Uses pretrained models from Hugging Face for reliable performance.

---

## Models Used
- **Image Classification Model:**  
  - Base: `google/vit-base-patch16-224-in21k`  
  - Fine-tuned model loaded from Google Drive  
- **Translation Model:**  
  - `facebook/nllb-200-distilled-600M`
